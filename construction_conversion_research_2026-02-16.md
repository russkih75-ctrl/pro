# Исследование конверсии (кровля / фасады / заборы) + GitHub решения для интеграции

Дата: 2026-02-16  
Проект: WordPress `kvadratyra-theme` (Vite + vanilla JS), GEO кластер `kv-geo`  
P0‑конверсия: **звонок / Telegram** (цели Метрики `phone_click`, `tg_click`)

## 1) Эталоны (RU + world) — кого бенчмаркать и почему

### Россия (материалы/системы)

- **Grand Line** — сильная “машина конверсии через калькуляторы”:
  - калькуляторы/витрина: `https://www.grandline.ru/calculation.html`
  - кровля: `https://www.grandline.ru/roofcalc/`
  - паттерн: выбор типа крыши → ввод размеров → **комплект + доборы** → “заказать расчёт от эксперта”.

- **Металл Профиль** — системный подход “калькулятор → спецификация → дилер/подрядчик”:
  - калькулятор крыши: `https://calcroof.metallprofil.ru/`
  - раздел калькуляторов: `https://metallprofil.ru/shop/pokupatelyam/calculators/`
  - паттерн: выбор профиля/покрытия/толщины → расчёт → следующий шаг через дилерскую сеть/контакт.

- **Технониколь / SHINGLAS** — эталон “комплектующих” для мягкой кровли:
  - калькулятор SHINGLAS: `https://www.tn.ru/calculators/shinglas/`
  - паттерн: геометрия + коллекция/цвет → **полный перечень** (ковры, планки, гвозди, мастика, аэраторы, проходки) → форма запроса помощи.

### Мир (конверсия через “find a pro” + гарантии + подбор)

Эталонная логика у топ‑брендов: **“подбор/оценка → найти подрядчика → получить смету”**.

- **GAF**:
  - квиз подбора подрядчика: `https://www.gaf.com/en-us/roofing-contractors/residential/contractor-match`
  - каталог подрядчиков: `https://www.gaf.com/en-us/roofing-contractors/residential`
  - паттерн: “под ключ через сертифицированных” + сильные гарантии.

- **Owens Corning**:
  - поиск подрядчиков: `https://owenscorning.com/en-us/roofing/contractors`
  - паттерн: образовательный контент + “найти подрядчика” как главный CTA.

- **CertainTeed**:
  - “Need an estimate” (форма → до 3 подрядчиков): `https://www.certainteed.com/need-an-estimate`
  - паттерн: **одна форма** → “в течение X времени свяжутся” → доверие через credentialing.

Дополнительно по фасадам/заборам (world‑паттерны калькуляторов):
- Фасады/сайдинг: **James Hardie** / **CertainTeed** (часто калькуляторы “площадь стен → openings → estimate”).
- Заборы: **Trex Fencing** (Build & Price / калькулятор материалов): `https://trexfencingfds.com/get-pricing/material-calculator/`

## 2) Точки максимальной конверсии (P0/P1/P2) — строительная ниша

Ниже — “где рождается заявка” по наблюдаемым паттернам лидеров и маркетплейсов.

### P0 — самое сильное (обычно даёт основной прирост)

1) **Оффер на первом экране = результат + срок + низкий риск**
   - Формула: *результат* → *срок* → *гарантия/договор* → *что дальше*.
   - На вашем сайте это уже частично есть (hero в `front-page.php`).

2) **CTA не “отправить”, а “получить результат”**
   - Примеры формулировок:
     - “Получить смету за 15 минут”
     - “Рассчитать материалы и цену”
     - “Записаться на бесплатный замер”
   - Важно: рядом микро‑обещание: “без спама”, “ответ за 15 минут”, “договор/гарантия”.

3) **Калькулятор = не “стоимость”, а “следующий шаг к смете”**
   - Лидеры (Grand Line/SHINGLAS) выигрывают тем, что считают **систему**, а не одну цифру:
     - основное покрытие/материал
     - комплектующие/доборы
     - запас (обычно 10–15%)
   - Ключевой триггер конверсии: кнопка вида “Заказать расчёт от эксперта / Получить спецификацию”.

4) **“Карта доверия” рядом с CTA**
   - договор, гарантия, сроки, фото объектов, сертификаты, “почему нам верить”.
   - На вашем лендинге есть, но можно усилить “фактами” (цифры, документы, кейсы).

5) **Меньше трения: multi-step (как Profi.ru)**
   - Логика: “что нужно” → “параметры” → “контакт” → “что будет дальше”.
   - Меньше полей на шаг, выше завершение формы.

### P1 — сильное усиление (обычно вторым этапом)

6) **Локальная релевантность**
   - Город/область в заголовке/ответах, сроки доставки/выезда.
   - У вас это уже прокачано через GEO‑кластер `kv-geo`.

7) **Прозрачность расчёта**
   - “что включено / что не включено”, “от чего зависит цена”.
   - Таблица факторов = меньше тревоги → больше отправок.

8) **Визуальная “спецификация”**
   - На результатах калькулятора: список материалов, кол-ва, единицы измерения, запас.
   - Возможность “отправить себе в Telegram/на почту” повышает лид‑качество.

9) **Sticky/плавающий CTA**
   - особенно на мобиле: кнопка “Позвонить”/“Telegram” остаётся доступной.
   - У вас уже есть `floating-cta` в `footer.php` — это плюс.

### P2 — рост и качество лида

10) **Кейсы с цифрами**
   - “было/стало”, площадь, срок, материал, цена диапазоном, гарантия.

11) **Контент “answer-first” как продажа**
   - короткий ответ + таблица + FAQ рядом с CTA (это одновременно и SEO, и конверсия).

## 3) Что улучшать в вашем калькуляторе (с точки зрения лидеров) — без внедрения

Сейчас калькулятор в теме — быстрый, но “одночисловой” (скорее калькулятор‑приманка).

Файлы:
- UI: `wp-content/themes/kvadratyra-theme/template-parts/quiz-calculator.php`
- Логика: `wp-content/themes/kvadratyra-theme/assets/src/main.js` (бандлится в `assets/dist/main.js`)

Что делают “как профи” (Grand Line / Металл Профиль / TN):

- **Шаг 1 (контекст)**: услуга (кровля/фасад/забор) + тип системы (пример: тип крыши / тип фасада / тип ограждения).
- **Шаг 2 (геометрия)**: не “площадь одним полем”, а понятные параметры (минимум 2–4), с подсказками и картинкой.
- **Шаг 3 (материал/покрытие)**: выбор 2–3 вариантов + “помочь выбрать”.
- **Результат**:
  - “ориентир по цене” + “почему это ориентир”
  - **комплект материалов** (хотя бы укрупнённо) + запас
  - CTA: “получить точную смету / спецификацию в Telegram”.
- **Лид‑форма**:
  - телефон/Telegram + удобное время звонка + город (если не из GEO) + комментарий/фото.

## 4) GitHub/OSS решения для интеграции (с лицензиями/рисками)

### 4.1 Анимированные emoji/иконки (строительная тематика)

- **Microsoft Fluent UI Animated Emoji** — `microsoft/fluentui-emoji-animated` (MIT)  
  Репозиторий: `https://github.com/microsoft/fluentui-emoji-animated`  
  Использование: взять нужные emoji (например “construction worker”, “hammer”, “wrench”, “house”) и вставлять как GIF/WebP в UI (hero/steps/benefits) аккуратно, без перегруза.

Риск/правило: не превращать лендинг в “мультфильм” — анимация только как функциональный акцент.

### 4.2 Multi-step wizard (vanilla) под лид-форму “как Profi.ru”

- **Enchanter** (MIT) — ванильный wizard для Bootstrap‑стиля форм  
  Репозиторий: `https://github.com/brunnopleffken/enchanter`  
  Что даёт: шаги, прогресс, валидация по шагам.

### 4.3 Маска телефона и валидация формы

- **IMask** (MIT): `https://github.com/uNmAnNeR/imaskjs`  
  Для: нормальная маска `+7 (999) 999-99-99`, меньше мусора в лидах.

- **JustValidate** (MIT): `https://github.com/horprogs/Just-validate`  
  Для: быстрые правила/сообщения ошибок без “тяжёлых” фреймворков.

### 4.4 Telegram‑доставка заявки (PHP)

- **Telegram Bot API SDK** (BSD 3‑Clause): `https://github.com/irazasyed/telegram-bot-sdk`  
  Для: отправлять заявку в Telegram ботом из WordPress (через AJAX handler).

### 4.5 Open-source калькуляторы кровли

- `pub-calculator-io/roofing-calculator` (WordPress plugin): `https://github.com/pub-calculator-io/roofing-calculator`  
  **Внимание**: лицензию нужно отдельно проверить в репозитории (в выдаче она не подтвердилась). Можно брать как референс UX/формулы, но интеграцию делать только после проверки лицензии.

- `quddusyo/Estimate-Roof` (React): `https://github.com/quddusyo/Estimate-Roof`  
  Как референс логики “площадь → доп. услуги → оценка”, не как прямой импорт (у нас WP+vanilla).

## 5) Чек-лист UI/копирайта именно для стройки (чтобы конвертило и проходило “Bible white”)

- **Единицы**: всегда показывать `м²` / `пог.м` / `мм`, не “условные единицы”.
- **Запас**: по умолчанию предлагать 10–15% (и объяснять почему).
- **Что включено**: материалы/доставка/монтаж — явно (и что НЕ включено).
- **Сроки**: “когда приедем на замер”, “когда смета”, “когда монтаж”.
- **Риски/ограничения**: погода, сложные узлы, демонтаж — честно, но с “выходом”.
- **Доверие**: договор, гарантия, сертификаты, фото объектов, реквизиты, адрес + карта.
- **Мобайл**: 1 экран = 1 мысль, крупные поля, фиксированный CTA.
- **Нейро/YATI**: на страницах услуг и GEO — H2‑вопросы + короткие ответы + таблицы + FAQ рядом с CTA.
