## 8. Ключевые выводы

### Спрос по районам
- **Мелкие районы (Аннинский, Бобровский, Таловский, Еланский, Кумылженский и т.д.)** — отдельных запросов с привязкой к районам практически нет (0-5 показов/мес). Жители ищут по ближайшему крупному городу или области.
- **Россошанский район** — 40 показов/мес, преобладают информационные запросы (монтаж, инструкции), коммерческих гео-запросов нет.
- **Михайловка + Урюпинск** — 34 показа/мес, аналогично информационные.

### Как ищут металлочерепицу жители этих районов
1. **По областному центру:** «металлочерепица Воронеж», «металлочерепица Волгоград», «металлочерепица Саратов» — основной паттерн поиска.
2. **По общему запросу + цена/купить:** «металлочерепица цена», «металлочерепица купить» — без гео-привязки, рассчитывая на Яндекс-геолокацию.
3. **Кросс-региональный спрос:** жители Тамбовской области ищут «металлочерепица воронеж» (24 показа) — считают Воронеж ближайшим крупным центром.
4. **Информационные запросы** составляют значительную долю: монтаж, инструкции, размеры, снегозадержатели — люди готовятся к самостоятельной установке.

### Рекомендации для SEO/рекламы
1. **Основные ключи для продвижения:**
   - металлочерепица купить [город]
   - металлочерепица цена [город]
   - металлочерепица для крыши [город]
   - кровля металлочерепица [город]

2. **Города-магниты** (куда идёт основной поисковый спрос из районов):
   - Воронеж — стягивает спрос из Тамбовской области
   - Волгоград — стягивает спрос из Урюпинска, Михайловки, Фролово
   - Саратов — стягивает спрос из Балашовского и Ртищевского районов
   - Белгород/Старый Оскол — Алексеевский район

3. **Для таргетинга на мелкие районы** — лучше использовать общие ключи без гео (металлочерепица купить, цена) с геотаргетингом по IP, а не ключи с названиями районов (спрос менее 5 показов/мес).

4. **Популярные бренды в регионе:** «металлочерепица монтеррей» — встречается в Тамбовской (32) и Саратовской (45) областях.

5. **Сопутствующие товары с поисковым спросом:**
   - снегозадержатели на металлочерепицу (46-49 показов)
   - монтаж металлочерепицы (информационный контент)
